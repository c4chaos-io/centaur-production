# Structure — how this repo is kept

Adopted 2026-11-26, at the creation of this repo.

## Files

- `README.md` — the calling card: the work, the proof,
  the philosophy, the links. The only file most visitors
  will read; keep it current and keep it short.
- `CENTAUR.md` — "What is a Centaur?": the definition,
  the split, the bottleneck doctrine. Promoted from the
  Yellow Rav3n repo (2026-11-26), where the original
  stays; this repo is its canonical home now.
- `CHARTER.md` — the unit, the signatures, the credit
  rules. Changes rarely; changes are Director
  decisions.
- `production-notes/` — the unit's production notes
  (PN-001, PN-002, …), added when PN-001 publishes,
  separately and after this repo's launch. PN-001 is
  the method note: the shoestring workflow of record
  and the documented, costed hybrid design (design
  only, not adopted).
- `directors-notes/` — the Director's notes for the
  unit itself (DN-001, DN-002, …), added when DN-001
  publishes, after this repo's launch. Project-level
  notes stay in the project repos.
- `posts/` — the unit's own launch and announcement
  entries, filed as repo entries (the launch entry:
  posts/2026-11-26-centaur-production-launch.md).
  If an entry is later adapted as a social post, the
  adaptation (cc lines, tags) happens then, in the
  posting lane — the repo entry is the clean text.
- `LICENSE.md` — the licensing map for this repo.
- `IP-AND-TRAINING-NOTICE.md` — marks, project IP, and
  training notice.
- `STRUCTURE.md` — this file.
- `assets/centaur-production-splash-v1.jpg` — the
  cover: the Beer Buddies poster from the Yellow Rav3n
  repo's CENTAUR.md page, re-lettered for this repo
  (title and bottom lines). The painting is unchanged.

## Rules

1. **Link, don't absorb.** Project canon, assets, and
   paper trails live in project repos. This repo points.
2. **The signature is the boundary.** The Work section
   lists only works signed *(A Centaur Production)*.
   Works signed ~C4Chaos / Fluffy (TPS, the EPIC
   anthology, the Letter) live in the separate
   "From the Same Centaur" section — linked, never
   absorbed, never presented as production works.
3. **One line per project.** A new project earns a
   README entry and a link when its repo is live —
   deferred repos are named without links (the Letter).
   Launched only: the card names only projects that
   have launched and are live in their own repos.
   Unlaunched projects are not mentioned at all —
   no placeholders, no teasers — until they launch.
4. **Numbers are dated.** The proof strip in the README
   cites the costing of record; when a new costing
   supersedes it, update the strip and the method note
   together.
5. **No project news here.** Launches, episodes, and
   releases are announced in their own repos. This repo
   changes when the map changes.
6. **Reciprocity.** This repo links out to every
   project repo, and every project repo links back
   here. One family, both directions: a visitor who
   lands anywhere can reach the unit, and from the
   unit can reach everything.
7. **The shoestring record lives here.** This repo
   is the historical record of the shoestring
   budget's development and its future evolution
   (Director's ruling, 2026-11-26). Every shoestring
   budget post actually posted on X is logged in
   posts/ as prior art, in order, with its numbers
   as posted on its date — drafts are never filed
   here; a post enters the record when it ships;
   future corrections and costings publish through
   this repo. The record of record:
   posts/2026-11-26-the-shoestring-history.md.
   (Rule 5 exception: budget posts are production
   history, not project news.)
